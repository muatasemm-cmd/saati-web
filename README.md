# ساعاتي للويب

نسخة ويب عربية تعمل كتطبيق PWA لتسجيل الدوام وحساب الأجر والسلف والدفعات.

## الخصائص

- تسجيل بداية الدوام ونهايته مع عداد مباشر.
- تعديل تاريخ ووقت بداية الدوام أثناء تشغيله، مع تحديث العداد والأجر وحفظ التعديل.
- دوام يدوي وتعديل السجلات وحذفها.
- حساب الأجر العادي والإضافي والعطل.
- تسجيل السلف والدفعات والمكافآت والخصومات.
- تقارير حسب الفترة وتصدير PDF وCSV.
- نسخ احتياطي واستعادة، مع استيراد نسخة تطبيق iPhone.
- وضع فاتح وداكن، وعمل دون إنترنت بعد الزيارة الأولى.

## الخصوصية

تُحفظ جميع بيانات الدوام محلياً في متصفح المستخدم ولا تُرفع إلى GitHub.
